DOM 요소 접근 방법

자바스크립트는 HTML 요소를 선택한 뒤, 선택한 내용, 속성, 스타일을 변경할 수 있다.

DOM 개념

DOM은 HTML 문서를 자바스크립트에서 다룰 수 있도록 객체 형태로 변환한 구조이다. 브라우저는 HTML을 읽고, 각 태그를 요소 객체로 만들어 계층 구조로 관리한다.

자바스크립트는 DOM을 이용해서 HTML에 접근하고, 요소의 내용, 속성, 스타일을 변경할 수 있다.

개념 정리

자바스크립트에서 HTML 요소를 가져온다는 것은 해당 요소를 나타내는 객체를 가져온다는 의미이다. 가져온 객체에는 textContent, innerHTML, style, value 등을 사용하여 화면의 내용을 변경할 수 있다.

HTML 요소 접근 메서드

DOM에서 요소를 가져올 때 사용하는 대표적인 메서드는 다음과 같다.

id로 접근하기

getElementById()는 id 속성값을 이용하여 HTML 요소 하나를 가져오는 메서드이다. id는 요소를 구분하기 위한 이름으로, 한 문서 안에는 id를 여러번 사용하지 않는다.
