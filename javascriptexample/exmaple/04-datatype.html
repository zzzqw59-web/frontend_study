변수와 자료형

자바스크립트에서 변수는 데이터를 저장하는 공간이고, 자료형은 변수에 저장되는 값의 종류를 의미한다. 자바스크립트는 변수 선언 시 자료형을 고정하지 않고, 저장되는 값에 따라 자료형이 결정된다.

변수 선언

변수는 데이터를 저장하기 위해 사용하는 이름이 있는 공간이다. 자바스크립트에서는 var, let, const를 사용하여 변수를 선언할 수 있다. 현재는 주로 let, const를 사용한다.

개념정리

let은 값을 다시 대입할 수 있는 변수를 선언할 때 사용한다. 같은 이름으로 재선언 할 수 없고, 블록 레벨 스코프를 가진다.

const는 값을 다시 대입하지 않을 변수를 선언할 때 사용한다. 같은 이름으로 재선언 할 수 없고, 재할당 할 수 없으며, 선언과 동시에 초기화 해야한다.

기본 자료형

기본 자료형은 하나의 값을 직접 표현하는 자료형이다. 대표적으로 문자열, 숫자, 논리값, undefined, null, bigint가 있다.

string

문자열을 나타내는 자료형이다. 작은 따옴표, 큰 따옴표, 백틱으로 작성할 수 있다.

number

정수와 실수 모두 나타내는 자료형이다.

boolean

true, false 값을 가지는 논리 자료형이다.

undefined / null

undefined는 값이 할당되지 않은 상태이고, null은 값이 없음을 의도적으로 표현한 것이다.

형변환

형변환은 값의 자료형을 다른 자료형으로 바꾸는 것을 의미한다. 사용자 입력값은 문자열로 처리되는 경우가 많으므로, 계산이 필요한 경우 숫자로 변환해야 한다. 자바스크립트에서는 Number(), String(), Boolean() 등을 활용하여 자료형을 변환할 수 있다.
