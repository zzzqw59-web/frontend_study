HTML 학습 기록

오늘은 HTML 문서의 기본 구조와 자주 사용하는 태그를 학습했습니다.

오늘 배운 내용

HTML 문서는 <html>, <head>, <body< 태그를 기본구조로 가진다.

화면에 표시되는 대부분의 내용은 <body> 태그 안에 작성한다.

학습 상태

처음에는 HTML이 어렵다고 생각했다.

하지만 예제를 작성하면서 HTML의 구조를 조금씩 이해하기 시작했다.

간단한 코드 메모

        HTML 구조
        <!DOCTYPE>
        <html>
            <head>
                문서정보 작성
            </head>
            <body>
                화면에 표시할 내용 작성
            </body>
        </html>

기억할 표현

문단 태그는 <p>내용</p> 형태로 작성한다.
